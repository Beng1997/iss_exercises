# ISS Exercises

A collection of programming exercises and projects demonstrating various computer science concepts including data structures, algorithms, scripting, and network protocols.

## Repository Overview

This repository contains coursework and exercises covering fundamental programming concepts implemented in C, C++, and Bash. Each directory contains a complete project or set of related exercises with full source code and documentation.

## Directory Structure

### 📰 [Article-bash-script](./Article-bash-script)
Bash scripting exercise for web scraping news articles from YNetNews and analyzing mentions of political figures.

**Key Files:**
- News scraping and analysis script
- CSV output with results
- Assignment documentation

### 📊 [complex-ADT](./complex-ADT)
Complex Abstract Data Type implementation for managing student grades with a linked-list-based architecture.

**Key Files:**
- Grades management system in C
- Linked-list data structures
- Build configuration files

### 📈 [grades-and-statistics](./grades-and-statistics)
Statistical analysis tools for processing grade data with multiple C programs and a unified Bash orchestration script.

**Key Files:**
- Statistical calculation programs (mean, median, min, max)
- Histogram generation
- Automated statistics computation script

### 🌐 [simple-net-protocol](./simple-net-protocol)
Network protocol implementation featuring IP and port filtering with a firewall simulation.

**Key Files:**
- IP and port handling classes (C++)
- Packet filtering logic
- Firewall simulation script

### 🗂️ [stack-ADT](./stack-ADT)
Generic stack Abstract Data Type implementation with student data structure examples.

**Key Files:**
- Generic stack implementation
- Student data type
- Function pointers for polymorphic operations

## Technologies Used

- **C**: Core systems programming, data structures, and algorithms
- **C++**: Object-oriented network protocol implementation
- **Bash**: Scripting for automation, web scraping, and system orchestration
- **Make**: Build automation and dependency management

## Getting Started

Each directory contains its own README.md with specific instructions for:

- Dependencies and requirements

Each exercise is self-contained within its directory, including:
